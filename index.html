How it works

One report. Four teams. Zero confusion.

Every report moves through the same pipeline, so nothing sits unassigned.

1. Report

A citizen files a disaster report or hits SOS with their location and photos.

2. Verify

Admins triage the report, assign a severity level, and route it to the right team.

3. Respond

Volunteers and rescue teams accept tasks and coordinate delivery or extraction.

4. Resolve

NGOs log distributed resources and the case closes with a full audit trail.

Built for every responder

Five roles, one shared operating picture.

Citizen

Report & request help

File disaster reports, send an SOS, locate nearby relief camps, and search missing persons.

Volunteer

NGO

Manage relief supply

Track inventory in real time and coordinate distribution across active relief camps.

Rescue Team

Run field operations

Receive assigned cases, update status from the field, and hand off to relief once safe.

Admin

Oversee the whole board

Verify reports, manage users and camps, allocate resources, and monitor analytics.
